🎐ตัวอย่างลิงก์ (Link Example)

ผลลัพธ์
ไปยังเว็บไซต์มฟาวิทยาลัย เปิด Google ในแท็บใหม่ 📬ส่ง Email ถึงผู้สอน ← กลับไปหน้าแรก
Code HTML
  1. 1<a href = "https://www.npru.ac.th" > เว็บไซต์มหาวิทยาลัย </a>
  2. 2<a href = "https://www.google.com" target = "_blank" > เปิด Google ในแท็บใหม่ </a>
  3. 3<a href="mailto:teacher@example.com">ส่งอีเมล</a>
  4. 4<a href="index.html">กลับหน้าแรก</a>
